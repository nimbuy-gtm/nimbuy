# Nimbuy — nimbuy.github.io (move to nimbuy.io after the first paid client)

Business site: free AWS Marketplace listing audit plus the Listing Optimize, Listing Launch
and Launch Sprint offers. Plain HTML, CSS and JavaScript, no build step. Deployed with
GitHub Pages; the `CNAME` file holds the custom domain.

```
index.html              the whole site (audit, offers, founder, FAQ)
css/style.css           styling (copied from the personal portfolio; edit here for Nimbuy)
js/listing-check.js     7-dimension listing audit, runs in the browser
js/listing-benchmark.js aggregates only, generated by ../tools/build-benchmark.js
js/enquiry.js           offer briefs → a ready email to nimbuy@PLACEHOLDER.example (no CRM, nothing stored)
js/assistant.js         offline offer guide (no AI, no network)
js/main.js              nav, reveals, chart, count-up
assets/                 favicon, founder photo, social preview (og.png, a 1200×630 shot of the page)
```

This site does not link to the personal portfolio, and the portfolio does not link here.
Keep it that way: no employer names or employer work on this site.

## Run locally

```bash
python -m http.server 5175
```

## Refresh the benchmark

```bash
node ../tools/build-benchmark.js path/to/listings_<date>.csv
```
Writes `js/listing-benchmark.js` here and in the portfolio.
